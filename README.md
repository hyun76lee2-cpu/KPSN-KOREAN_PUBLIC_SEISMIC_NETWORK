# IMM 관측 지도

참여자들이 1초 간격 IMM 관측값을 올리고, 누구나 지도에서 볼 수 있는 사이트예요.
올리는 값: IMM_(0.2,0.5), IMM_(0.5,1.5), IMM_(1.5,7.5), 대표 IMM(0.1~10초 최댓값)과 대표 주기.
개인 관측 기록 공유용이며 지진 예보·경보가 아니에요.

## 참여하기

- **폰**: 사이트를 폰 브라우저로 열고 "내 관측소로 참여하기"에서 이름을 적고 참여 시작. 위치는 직접 정할 수 없고, 참여할 때마다 그 기기의 현재 위치를 받아 약 1 km 단위로 반올림해 올려요 (위치 권한 필요). 폰은 바닥에 테이프로 고정하고, 처음 한 번 조용할 때 잡음 측정(30초)을 해요. 아이폰은 시작할 때 동작 센서 권한을 물어봐요.
- **ADXL355 (컴퓨터)**: `pc/imm_share.example.json`을 `imm_share.json`으로 복사해 값을 채우고
  `python imm_live.py --serial COM5 --share imm_share.json`
  CSV 재생(`--csv`)과 함께 쓰면 공유하지 않아요. 지도에는 실제 측정값만 올라가요.
  처음 실행할 때 익명 계정이 만들어지고 `imm_share_token.json`에 저장돼서, 다음에도 같은 관측소로 이어져요.

## 지도 보기 설정

- **직접 입력 위치 관측소**: **컴퓨터(`imm_live.py`)로 참여한 관측소는 위치를 설정 파일에 직접 적기 때문에 기본으로 숨겨요**. "직접 입력 위치 관측소도 보기"를 켠 사람에게만 보여요.
- **오프라인 관측소 숨기기**: 신호가 끊긴 관측소를 즉시, 10분, 1시간, 6시간, 24시간 뒤에 숨길지 고를 수 있어요 (기본 24시간). 보는 사람마다 따로 저장돼요.
- **층수 보정 (폰)**: 고층에서 참여할 때 최고 층수와 지금 층을 넣으면 건물 증폭을 뺀 지반 추정값을 올려요. 조용할 때 "고유주기 측정"을 하면 더 정확해요.

## 데이터와 개인정보

- 공개되는 것: 관측소 이름, 위치(소수 둘째 자리, 약 1 km 단위), 센서 종류, 1초 관측값.
- 30초 넘게 갱신이 없으면 지도에서 회색, 하루가 지나면 숨겨요. 데이터 자체는 Firebase 콘솔에서 지울 수 있어요.
- 각자 자기 관측소 경로에만 쓸 수 있어요 (익명 로그인 uid 기준 보안 규칙).
